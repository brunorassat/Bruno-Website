## Why a home agent?

I wanted a personal AI assistant that was:

- **Always on** — no waking up a laptop, no cloud subscription to babysit
- **Private** — my queries stay on my own hardware or go to a provider I choose
- **Cheap** — both to buy and to run

The Raspberry Pi Zero 2W costs around $15 and sips power. [PicoClaw](https://picoclaw.net/) is an open-source Go binary that weighs under 10MB, starts in under a second, and connects your chosen AI model to Telegram. Together they make a surprisingly capable home agent.

| Item | Notes |

| Raspberry Pi Zero 2W | ~$15 |
| MicroSD card (16GB+) | Class 10 / A1 recommended |

| Micro-USB OTG adapter + keyboard | Only needed for initial setup if no SSH |
| An AI model API key | DeepSeek or Groq have generous free tiers |
| A Telegram account | Free |

## 1. Flash Raspberry Pi OS Lite

Download [Raspberry Pi Imager](https://www.raspberrypi.com/software/) and choose:

- **OS**: Raspberry Pi OS Lite (64-bit)
- **Storage**: your MicroSD card

Before writing, open **Advanced options** (the gear icon) and configure:

- Hostname (e.g. `picoclaw`)
- Enable SSH with a password or your public key
- Wi-Fi SSID and password

Flash the card, slot it into the Pi, and power it on.

---

## 2. SSH in and update

Find your Pi's IP on your router, then:

```bash
ssh pi@picoclaw.local
# or ssh pi@<IP>

sudo apt update && sudo apt upgrade -y
```

---

## 3. Set up a Telegram Bot

1. Open Telegram and search for **@BotFather**
2. Send `/newbot` and follow the prompts (pick a name and a username ending in `bot`)
3. Copy the **HTTP API token** BotFather gives you — you'll need it in the next step

---

## 4. Get an AI model API key

PicoClaw supports several providers. For a free start, grab a key from:

- [Groq](https://console.groq.com) — extremely fast inference, generous free tier
- [DeepSeek](https://platform.deepseek.com) — great value for money
- [OpenRouter](https://openrouter.ai) — access many models through one key

---

## 5. Download PicoClaw

PicoClaw ships as a single binary. On the Pi, run:

```bash
# Download the latest ARM64 release
curl -Lo picoclaw https://github.com/yourusername/picoclaw/releases/latest/download/picoclaw-linux-arm64
chmod +x picoclaw
sudo mv picoclaw /usr/local/bin/picoclaw
```

> **Tip:** Check the [PicoClaw releases page](https://picoclaw.net/) for the exact URL of the latest ARM64 build.

---

## 6. Create the config file

Create a directory for PicoClaw's config and data:

```bash
mkdir -p ~/.config/picoclaw
nano ~/.config/picoclaw/config.yaml
```

Paste in a config like this (adjust the values):

```yaml
bot:
  platform: telegram
  token: "YOUR_TELEGRAM_BOT_TOKEN"

model:
  provider: groq          # or: deepseek, anthropic, openai, openrouter
  api_key: "YOUR_API_KEY"
  name: "llama-3.3-70b-versatile"   # model name for your chosen provider

memory:
  enabled: true
  path: ~/.config/picoclaw/memory.json

log_level: info
```

Save and close (`Ctrl+O`, `Enter`, `Ctrl+X`).

---

## 7. First run

```bash
picoclaw --config ~/.config/picoclaw/config.yaml
```

Open Telegram, find your bot, and send it a message. You should get a reply within a couple of seconds. If something goes wrong, check the terminal output — PicoClaw logs are human-readable.

---

## 8. Install as a systemd service

So PicoClaw survives reboots:

```bash
sudo nano /etc/systemd/system/picoclaw.service
```

Paste:

```ini
[Unit]
Description=PicoClaw Home AI Agent
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=pi
ExecStart=/usr/local/bin/picoclaw --config /home/pi/.config/picoclaw/config.yaml
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Enable and start it:

```bash
sudo systemctl daemon-reload
sudo systemctl enable picoclaw
sudo systemctl start picoclaw
sudo systemctl status picoclaw
```

You should see `active (running)`. Your agent is now live 24/7.

---

## 9. Set up scheduled tasks

One of PicoClaw's killer features is built-in cron scheduling. You can ask it directly in Telegram:

```
/schedule 0 8 * * 1-5 | Give me a brief summary of what I should focus on today
```

This fires every weekday at 8am and sends you a message. No extra tooling required.
