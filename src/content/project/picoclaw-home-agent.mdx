## Why PicoClaw?

Most home-assistant setups require running a full server, a Docker stack, or a cloud subscription. PicoClaw is the opposite: a **single statically-compiled binary** that ships as one file, reads one config, and connects your chosen AI model (DeepSeek, Groq, Anthropic, OpenAI, OpenRouter…) to a messaging platform. On a Pi Zero 2W, it starts faster than the network is ready.

Key properties that made it the right pick:

- **Under 10MB RAM** — the Pi Zero 2W has 512MB total; PicoClaw barely shows up
- **Sub-1-second startup** — boots before the shell prompt finishes loading
- **Single binary, no runtime** — no Node, no Python, no Docker; just one file
- **Built-in cron** — schedule tasks directly from Telegram without extra tooling
- **Multi-model** — switch providers in one config line

## Setup

### 1. Flash Raspberry Pi OS Lite (64-bit)

Using [Raspberry Pi Imager](https://www.raspberrypi.com/software/), I flashed the card with SSH and Wi-Fi pre-configured via Advanced Options — no keyboard or monitor needed.

### 2. Download PicoClaw

```bash
curl -Lo picoclaw https://github.com/picoclaw/picoclaw/releases/latest/download/picoclaw-linux-arm64
chmod +x picoclaw
sudo mv picoclaw /usr/local/bin/picoclaw
```

### 3. Create the config

```yaml
# ~/.config/picoclaw/config.yaml
bot:
  platform: telegram
  token: "YOUR_TELEGRAM_BOT_TOKEN"

model:
  provider: groq
  api_key: "YOUR_GROQ_API_KEY"
  name: "llama-3.3-70b-versatile"

memory:
  enabled: true
  path: ~/.config/picoclaw/memory.json
```

The Telegram bot token comes from [@BotFather](https://t.me/botfather) — a two-minute setup. I used [Groq](https://console.groq.com) as the inference provider for its free tier and very fast response times.

### 4. Run as a systemd service

```ini
# /etc/systemd/system/picoclaw.service
[Unit]
Description=PicoClaw Home AI Agent
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=pi
ExecStart=/usr/local/bin/picoclaw --config /home/pi/.config/picoclaw/config.yaml
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now picoclaw
```

The agent now starts automatically on every boot and restarts itself on failure.

## Outcomes

- **Always available:** The Pi has been running for weeks without a single manual restart.
- **Private:** Queries go to a model provider of my choice — nothing sits in a third-party chat history.
- **Negligible cost:** ~1.2W idle draw. At French electricity rates that's under €2/year.
- **Zero maintenance:** `systemd` handles crashes; `apt` updates handle security.

## What's Next

- **Home automation:** Connect PicoClaw to Home Assistant via webhooks to control lights and plugs with natural language.
- **Voice input:** Add a USB microphone and Whisper for voice commands from the kitchen.
- **Multi-model routing:** Use a fast cheap model for quick queries and a more capable one for complex tasks, selected automatically.

The Pi Zero 2W is barely warm to the touch. There's plenty of headroom to grow.
